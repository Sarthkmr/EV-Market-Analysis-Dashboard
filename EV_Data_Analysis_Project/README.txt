# Electric Vehicle Market Analysis Dashboard

## Project Overview

This project analyzes Electric Vehicle (EV) registration data to identify trends in EV adoption, manufacturer performance, city-wise distribution, vehicle types, and electric range characteristics.

## Tools Used

* Python (Pandas, Matplotlib)
* MySQL Workbench
* Power BI
* Microsoft Excel

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. SQL Analysis
5. Power BI Dashboard Development
6. Business Insights Generation

## Key Insights

* Tesla is the dominant EV manufacturer.
* Battery Electric Vehicles (BEVs) are more popular than PHEVs.
* Seattle has the highest EV adoption.
* EV registrations increased significantly after 2021.
* King County leads in EV registrations.
