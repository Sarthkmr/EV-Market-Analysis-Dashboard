# EV Market Analysis Dashboard

An end-to-end Data Analytics project using **Python, MySQL, and Power BI** to analyze **279K+ Electric Vehicle records**.

## Key Highlights

* Cleaned and analyzed EV registration data
* Performed SQL-based business analysis
* Built interactive Power BI dashboards
* Identified EV adoption trends and market leaders
* Generated actionable business insights

## Tools Used

Python | MySQL | Power BI | Pandas | SQL

## Key Insights

* Tesla is the leading EV manufacturer
* BEVs are more popular than PHEVs
* Seattle has the highest EV adoption
* EV registrations grew rapidly after 2021

This project demonstrates data cleaning, SQL analysis, data visualization, dashboard development, and business intelligence skills.
